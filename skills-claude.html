1 · Instálalas

  1. Descomprime el ZIP y copia cada carpeta en la carpeta de skills de tu usuario: C:\Users\TU_USUARIO\.claude\skills\ en Windows o ~/.claude/skills/ en Mac. Así las tienes en todos tus proyectos.
  2. Si solo las quieres en un proyecto, cópialas en la carpeta .claude/skills/ de ese proyecto.
  3. Abre una sesión nueva de Claude Code. Si no, no las ve.
  4. Abre cada SKILL.md y cambia lo que sea tuyo (por ejemplo, tu texto de «Sobre mí»). Es texto normal.

2 · Las skills de Anthropic (gratis)

En Claude Code, en la terminal (el panel de VS Code no tiene el comando /plugin):

PASO 1

Añadir la tienda de skills

/plugin marketplace add anthropics/skills
PASO 2

Instalar las skills

/plugin
(ve a «Discover», busca document-skills e instálalo para tu usuario)

Las que más uso: las de documentos (Excel, Word, PowerPoint y PDF), frontend-design para webs, skill-creator para crear skills y webapp-testing para probar webs.

3 · Crea la tuya con skill-creator

PROMPT

Crear una skill

Usa la skill skill-creator de Anthropic para crear una skill que [lo que quieres que haga]. Siempre igual: [la estructura, en orden]. Tono [cómo]. Guárdala en mi carpeta de usuario para tenerla en todos los proyectos.

La regla: cualquier cosa que le pides a Claude más de dos veces, y siempre le explicas igual, es una skill.

Trucos

  • Lo más importante es la descripción: pon las palabras que usarías tú al pedirlo
  • Una skill, una tarea
  • Si no se activa sola, nómbrala: «usa la skill tal para…»
  • Si falla, dile «esto ha salido mal por esto, mejora la skill»

Lo que nadie te cuenta

  • Las de Anthropic son de demostración: pruébalas antes de fiarte
  • Una skill puede llevar scripts: mira qué hay dentro antes de instalar una que no conoces
  • No siempre se activa sola
  • Es tan buena como lo bien que expliques lo que quieres
