Tu guía

Aquí tienes la guía

Así lo tengo montado yo. Sigue los pasos en orden y no te saltes el de seguridad.

Lo que necesitas

  1. Un servidor (VPS) con Ubuntu. Es lo que hace que funcione las 24 horas aunque apagues el ordenador. Yo uso un KVM 2 de Hostinger, el mismo donde tengo mis automatizaciones de n8n.
  2. El cerebro: un modelo de IA. Yo uso Claude Sonnet con mi suscripción de Claude, sin pagar una clave de API aparte. Hermes también admite otros proveedores (OpenRouter, OpenAI, Nous Portal…).
  3. Telegram en el móvil, para hablarle.

Paso a paso

  1. Un usuario aparte. Entra en tu servidor y crea un usuario solo para el asistente (adduser hermes). Así no puede tocar lo que tengas en el resto del servidor.
  2. Instala Hermes Agent con ese usuario. El instalador oficial es curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash. Después, source ~/.bashrc y comprueba que funciona con hermes --version. Consejo: descarga antes el script y léelo, o pídele a una IA que te lo explique.
  3. Conecta el cerebro con hermes setup: elige el proveedor (en mi caso, Anthropic con mi cuenta de Claude) y el modelo. Para un asistente, Sonnet va de sobra.
  4. Crea tu bot de Telegram. Escribe a @BotFather, manda /newbot, ponle nombre (el mío se llama Batiste) y guarda el token que te da. Ese token no se lo pases a nadie.
  5. Conecta Telegram con hermes gateway setup: pega el token y pon tu ID de usuario de Telegram como único permitido (lo sabes escribiendo a @userinfobot). Así el bot solo te responde a ti.
  6. Déjalo encendido siempre con hermes gateway install y hermes gateway start. Comprueba que todo está bien con hermes status o hermes doctor.
  7. Mándale un audio. En mi servidor los audios se transcriben ahí mismo, sin mandar tu voz a otro servicio. Si no te entiende los audios, revisa la parte de voz con hermes setup.

✅ Sí

  • Darle solo los accesos que necesita y ampliar poco a poco.
  • Guardar las claves en el servidor.

❌ No

  • Pegar claves o contraseñas en el chat o en una captura.
  • Darle tu correo o tus cuentas el primer día.
  • Pasarle datos sensibles de tus clientes sin pensarlo.
