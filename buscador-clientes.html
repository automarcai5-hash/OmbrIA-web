Cómo ponerla en marcha:

  1. En n8n, crea un flujo nuevo, abre el menú ⋯ → Import from File y elige el archivo descargado.
  2. En Google Cloud, activa Places API (New), crea una API key y ponle topes diarios en Cuotas para no llevarte sorpresas en la factura.
  3. En n8n, crea una credencial Header Auth con el nombre X-Goog-Api-Key y tu API key como valor. Asígnala a los dos nodos de Google.
  4. En Airtable, crea una tabla con los campos del nodo «Clasificar y preparar ficha» (Nombre, Actividad, Teléfono, Email, Página web, Google Place ID…). Conecta tu cuenta y cambia TU_BASE_ID y TU_TABLA_ID en los dos nodos de Airtable.
  5. Edita los bloques CONFIGURA AQUÍ: qué buscar, en qué zonas, tu provincia y las actividades de tu sector.
  6. Pruébalo con «Probar manualmente». Cuando funcione, actívalo: se lanza solo los lunes y martes a las 8:00 (lo puedes cambiar).

Los datos salen de fichas públicas de Google Maps y de las webs de las empresas. Revísalos antes de llamar y trátalos con cuidado.
